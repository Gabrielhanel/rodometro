# Média de Consumo de Combustível - Projeto Mobile

Aplicativo mobile desenvolvido com **Expo** e **React Native** que permite calcular a **média de consumo de combustível** de um veículo.

## Funcionalidades

- 📥 **Entrada de Dados**:
  - Inserção da quilometragem percorrida (KM).
  - Inserção da quantidade de litros de gasolina consumidos.

- 🧮 **Cálculo**:
  - Cálculo automático da média de consumo (Km/L).

- 📊 **Classificação do Consumo**:
  - Exibição de uma classificação baseada na média:
    - **A**: Mais de 12 Km/L
    - **B**: Até 12 Km/L
    - **C**: Até 10 Km/L
    - **D**: Até 8 Km/L
    - **E**: Até 4 Km/L

- 🔄 **Navegação**:
  - O usuário insere os dados na primeira tela e é redirecionado para a segunda tela para visualizar o resultado.

## Tecnologias Utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [React Navigation](https://reactnavigation.org/)
